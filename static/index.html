CONNECT YOUR INBOX

Gmail, with read-only access.

Google grants permission to read your mailbox. Autopilot searches for job-related messages and stores matching emails locally for assessment. It cannot send, edit, or delete your Gmail messages.

  1. Create a Google Cloud project

    Enable the Gmail API in Google Cloud Console ↗.

  2. Configure Google Auth Platform

    Set up Branding and an External audience in Testing mode. Add your Gmail address as a test user. Add the gmail.readonly scope under Data Access.

  3. Create or use an OAuth client

    Use a Desktop app or Web application client. For a Web client, save this exact Authorized redirect URI in Google Cloud: http://127.0.0.1:8000/ (including the trailing slash). Download its JSON and save it in this project as config/gmail_credentials.json. Keep this file private. Full instructions are in GMAIL_SETUP.md.

  4. Connect, then scan

    Click Connect Gmail, grant read access on Google, then Scan job emails. Each scan checks up to 100 matching messages. Continue with the next batch when available.

Your connection stays under your control.

Tokens stay in server memory. Restarting the server requires reconnecting. Disconnect attempts to revoke access and clears the local connection; already imported emails remain in your tracker.

This is one local workspace for one person. Gmail threads group messages; separate threads for the same job may appear as separate applications. Search and keyword filtering can miss messages, and an assessment is not a guarantee of legitimacy.

UNDER THE HOOD

One inbox. One clear picture.

  1. Bring your inbox

    Import a JSON or .mbox file, up to 10 MB and 1,000 emails. Everything stays on this computer.

  2. One label for every message

    Each new email becomes applied, interview, rejected, offer, or scam. Re-importing the same message skips classification.

  3. Know what needs your attention

    Scam flags include the specific suspicious text. Active applications surface after seven quiet days. Logging a follow-up means you sent it elsewhere; this app never sends email.

This prototype uses keyword rules, which can miss scams and misread context. A flag is a reason to review, not a verified fraud finding. An unflagged message is not a guarantee of safety.
